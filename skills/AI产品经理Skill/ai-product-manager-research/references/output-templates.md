# 输出模板

只使用当前流程需要的模板。根据启动模式、调研深度和项目特点调整各章节的详细程度，不要为了套用模板而生成空章节。

## 调研计划

1. **研究对象与启动模式**
   - 启动模式：产品想法 / 指定产品 / 用户需求
   - 对研究对象和预期目标的理解
   - 指定产品模式：识别到的产品主体、官网、版本或地区，以及识别依据
2. **当前理解与关键假设**
3. **核心研究问题**
4. **研究范围**
   - 纳入范围
   - 排除范围
   - 地域与时间范围
5. **研究方法与拟用来源**
6. **竞品与替代方案选择方向**
7. **计划交付物**
8. **需要用户纠正或确认的内容**

结尾只提出一个直接问题，请用户确认或修改调研计划。不得在同一轮开始完整调研。

## 市场调研

1. **执行摘要**
2. **市场定义与边界**
3. **市场现状、规模与趋势**
4. **需求驱动因素与关键变化**
5. **竞品与替代方案矩阵**
6. **重点竞品分析**
7. **定价与商业模式**
8. **用户反馈中的共性信号**
9. **中国市场与海外参照**
10. **对产品决策的意义**
11. **证据局限与冲突信息**

引用应放在其支持的结论附近。只有在有助于后续查找时，才在结尾增加简洁的来源索引。

## 用户画像

围绕 2–4 个有证据支持的用户群体形成结论文档。不要把所有图表集中在开头；每个主要结论章节都要依次包含“本章结论 → 对应图表 → 读图结论 → 证据与置信度”。默认章节结构如下，可根据 B2B、B2C 或内部工具调整，有分析依据时保留对应章节图表，完全缺乏依据时展示证据缺口表：

1. **核心用户与用户分布**
   - 说明核心用户、次要用户和各群体的识别特征
   - 添加用户分布条形图、堆叠图或环形图
2. **用户任务与使用场景**
   - 说明核心任务、典型场景、使用频率和期望结果
   - 添加任务重要性图、场景频率图或场景矩阵
3. **用户痛点**
   - 说明不同群体的痛点、发生频率、严重程度和未满足程度
   - 添加痛点频率与严重程度图、热力图或二维矩阵
4. **当前替代方案与切换成本**
   - 说明现有解决方式、采用阻力和切换成本
   - 添加替代方案对比图或切换成本矩阵
5. **用户付费意愿**
   - 说明付费动机、价格敏感度、可接受价格区间和购买标准
   - 添加付费意愿分布图、价格区间图或用户群体对比图
6. **用户使用频率、留存与流失**
   - 说明使用频率、留存驱动因素、留存潜力和主要流失原因
   - 添加留存曲线、留存潜力对比图、使用频率图或流失原因图
7. **获客渠道与购买决策**
   - 说明发现渠道、触达效率、主要顾虑和购买决策角色；B2B 场景区分使用者、推动者、决策者和付费者
   - 添加渠道偏好图、触达效率图、漏斗图或决策链路图
8. **用户群体优先级与建议**
   - 给出建议优先进入的核心群体，并解释理由
   - 添加用户群体优先级矩阵；横轴为触达与转化可行性，纵轴为综合价值

每张图表必须与所在章节的数据、分类和统计口径一致，包含标题、图例、单位、数据性质及来源说明。估算或相对等级必须注明依据和置信度。具体输出按 [visualization-spec.md](visualization-spec.md)：ECharts 数据图、Mermaid 流程图和明细表。缺渲染器时交付可渲染规范＋数据表，标明待渲染；缺少分析依据时展示证据缺口表。只有研究方法、证据局限、来源说明等没有独立分析数据的辅助章节可以不配图。

## 产品机会点与风险

先提供按优先级排列的机会点概览。每个机会点包括：

- 机会点描述
- 目标用户群体和未解决的痛点
- 支持证据
- 建议的产品切入方式
- 用户价值与商业价值
- 可行性、依赖条件与差异化
- 关键假设
- 最小可行验证方式
- 主要风险与缓解措施
- 优先级：高 / 中 / 低，并说明理由

需要时增加条件式风险清单，包括风险、触发条件、发生可能性、影响程度、缓解措施，以及责任人或监控信号。

## 导出

合并报告使用以下顺序：

1. 标题、生成日期和目录
2. 执行摘要
3. 研究范围、研究方法与关键假设
4. 按工作流顺序排列用户选择的已完成模块
5. 关键决策与下一步行动
6. 来源索引

拆分为多个文件时，使用稳定的数字前缀：

- `01-调研计划.md`
- `02-市场调研.md`
- `03-用户画像.md`
- `04-产品机会点与风险.md`

文件夹或合并文件名应包含适合文件系统使用的项目名称和生成日期。

导出用户画像时，应保留各主要结论章节中的对应图表。Markdown 无法嵌入某种图表格式时，同时保留对应的 Markdown 数据表，确保关键信息不会因查看环境不同而丢失。
