# 产品经理工作台 v1.0 需求与交付边界

面向本机个人使用的 macOS 应用，基于官方 DeepSeek Harness SDK，三类 skill 负责研究、立项和产品执行。三份源 skill 保持原样。

|阶段|模块与产物|
|---|---|
|市场／用户／机会研究|市场与竞品研究、用户研究、机会判断；研究报告、证据和待验证假设|
|立项|立项报告，含 MVP 简介、价值、优先级和风险|
|产品设计|完整 MVP、PRD、交互原型、流程；完整范围、需求、HTML 原型及流程文档|
|埋点与验收|事件与属性方案、验收标准和测试场景|
|数据分析|漏斗、留存、A/B；代码计算的数据结果、图表和模型解释|
|迭代|复盘与下一轮决策、迭代行动|

用户可以从任意模块开始。前序产物可选择交接，也可手工输入、上传文件或对话后确认加入材料；模型推测不能冒充用户输入或真实数据。输出保存版本，文档支持 Markdown、HTML、JSON 等已有格式导出，原型在沙箱中预览。

文件支持 TXT/MD/CSV/JSON/PDF/DOCX/XLSX/PNG/JPG，预览确认后入库。OCR 使用本机 Apple Vision。联网支持公开网页、Tavily/Brave/SearXNG；动态公开页仅桌面可用。保留来源、提取方法与交接引用，搜索摘要与网页正文分开标注。

漏斗支持汇总人数和原始事件顺序窗口；留存支持队列汇总和事件数据，未成熟数据保持缺失。A/B 支持二元转化、连续均值和 2–6 组共享对照，使用 Holm 校正。统计口径必须明确，数值由代码计算。

模型设置允许多个连接，支持 OpenAI 兼容、DeepSeek Messages 和 Anthropic Messages 协议，测试连接与默认模型。Mac 项目与凭据状态使用系统钥匙串加密；会话日志仍是本机文件。关闭窗口保留运行任务，退出释放服务，重启恢复项目与历史。

当前交付 Apple Silicon/macOS 13+ 本地签名版本。正式分发能力包括 Developer ID、hardened runtime、公证与装订、每架构更新包及 HTTPS 更新配置；正式 Apple 服务、真实更新替换和 Intel 真机的验收依赖外部证书、凭据、托管及硬件。团队协作、账号云同步不在本版范围。
