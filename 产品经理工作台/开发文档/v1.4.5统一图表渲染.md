# v1.4.5 统一图表渲染与文字避让

旧报告此前只识别数字条形图和部分痛点矩阵，价格带、定性条形图、文本坐标矩阵等仍以代码块展示；横向条形图的分类轴标题又与长标签相交。

现在 Markdown 文档的图表进入统一入口：规范 chart 数据由 ECharts SVG 绘制，Mermaid 源码由 Mermaid 绘制，历史明确数字条形图/配套痛点矩阵自动解析；价格带、定性等级、明确坐标和标题标明的表格图分别使用 SVG 区间、等级点阵、坐标和表格布局。标题沿用原文。定性等级不从字符长度推测分值，缺失值仍明确展示。不能可靠结构化的字符示意图采用 SVG 原文布局，注明不推测坐标。普通程序代码和普通数据表不误转换。

横向条形图移除重复分类轴标题，限制长标签宽度、按数据行数分配高度；分类全文和依据仍在数据与来源中保留。SVG 使用文本转义及统一清理，没有执行原文 JS，没有访问外部绘图服务。各图保留放大、SVG/PNG 导出。原始报告未重写，无需重新调用模型。

验证：三项回归先复现失败，修复后 71 项单元/API 检查通过。综合浏览器检查覆盖九种图形实例以及放大、导出、独立滚动和窄屏。原用户画像的整份本地重放：11 个图形围栏、12 个 SVG 图表（含表格型图表），未转换代码块 0；全部 SVG 在浏览器实际渲染，下载与滚动通过。原报告仅在本地隔离环境使用，未传至模型服务。

安装 UI、签名、DMG 与 SHA256 核对通过。最终桌面检查因系统钥匙串授权等待而未完成，需用户本人完成授权；应用改动已经安装，原数据保持。
