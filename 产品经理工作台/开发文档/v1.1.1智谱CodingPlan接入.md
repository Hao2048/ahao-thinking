# v1.1.1 智谱 GLM Coding Plan 接入

模型设置新增厂商 ID `zhipu-coding`。普通流程保持选择厂商、填写 API Key、保存，自动设为当前连接。默认使用 `glm-5.3-flash`，OpenAI Chat Completions 协议，Base URL 为 `https://open.bigmodel.cn/api/coding/paas/v4`。高级设置可更换套餐支持的模型。当前 Harness OpenAI 兼容适配器直接调用，无新增依赖或修改源 skill。

不将套餐地址与普通 `api/paas/v4` 混用，也不在失败后自动回退按量计费接口。Key 获取链接指向个人套餐概览；团队用户应使用团队套餐 Key。保存后不回显 Key，换厂商清空输入，换地址或协议仍需显式提供新凭据。

2026-10-09 官方文档核对：[快速开始](https://docs.bigmodel.cn/cn/coding-plan/quick-start)、[模型切换](https://docs.bigmodel.cn/cn/coding-plan/latest-model)、[适用工具](https://docs.bigmodel.cn/cn/coding-plan/tool/others)。官方说明套餐限指定工具，本工作台未列入名单，界面与交付说明注明这一点；接口预设并不证明套餐授权，不伪装工具身份或绕过服务限制。没有真实套餐 Key，实际套餐授权与额度未验证。

验证复用厂商预设领域测试，增加浏览器选择、专用地址、默认模型、范围提示、只需 Key、保存和重新编辑测试；最终安装版按 `AIPM_TEST_PROVIDER=zhipu-coding` 验证原生预设配置和加密及生命周期。
