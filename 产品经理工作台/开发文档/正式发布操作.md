# 正式发布操作

本地安装包可用于本机验收。外部分发必须具备有效 Developer ID Application 证书与私钥、Apple 公证凭据、HTTPS 静态发布目录。Apple Development 证书不能替代。

1. 在目标架构 Mac 安装依赖、构建相邻 Harness，准备 Swift 与匹配的 macOS SDK。
2. 使用 `xcrun notarytool store-credentials` 在钥匙串建立自己的配置；不要把凭据写入仓库。
3. 在 `apps/workbench` 执行以下命令，值替换为真实配置：

```sh
export AIPM_SIGN_IDENTITY='Developer ID Application: YOUR ORGANIZATION (TEAMID)'
export AIPM_NOTARY_PROFILE='your-notary-profile'
export AIPM_RELEASE_BASE_URL='https://your-release-host.example/releases/'
npm run desktop:release
```

4. 只有 Apple 返回 Accepted 并装订验证成功后才分发正式 APP/DMG。上传生成的最终 ZIP 和对应 `latest-arm64.json`/`latest-x64.json` 到配置目录。不同架构分别构建和托管 feed。
5. 以正式旧版本安装到 Applications，配置对应 HTTPS feed，验证检查、下载、运行任务阻止安装、用户安装、退出和新版本恢复；升级前另备份资料。不要用本地签名包验证真实替换。

本机尚无 Developer ID 分发证书、公证配置和真实更新服务，正式发布与更新替换尚未实测。构建脚本不会上传或对外发布产物。
