# v1.4.0 助手统一执行与展示

`assistant-workspace.mjs` 提供 Skill 大纲、模块忙碌状态、上下文代次、材料检查与快照摘要。每次检查、生成和 HTML 转换只读取当前所属 Skill。`workspace.mjs` 统一前端运行、材料不足确认、清空及手动 HTML 操作；`document-view.mjs` 安全展示 Markdown、表格、内嵌图片和隔离 HTML。

| 接口 | 用途 |
| --- | --- |
| GET /api/state | 返回每个模块的默认大纲和来源依据 |
| GET/POST /api/projects/:id/assistant/:module/outline | 读取、保存自定义大纲并记录助手消息 |
| POST …/preflight | 调用本模块模型检查资料，返回判断、建议及检查编号 |
| POST /api/projects/:id/work | 校验检查编号与最新材料/对话/大纲摘要，冻结运行版本，助手执行并同步结果 |
| POST …/html | 逐份转换成功文档，缓存 htmlPresentation，再次查看不调用模型 |
| POST …/reset | 清除当前模块材料、对话及准备；代次递增，保留产物和已保存大纲 |

兼容内部旧 `/runs` 接口，执行仍进入同一任务与助手消息链；当前界面统一使用带资料检查的 `/work`。研究入口准备、提问与计划内容也进入助手记录。聊天可返回 workAction=run，实时回复结束后进入同一检查/确认流程，刷新历史不会自动重放。

运行保存 outlineSnapshot、conversationSnapshot 与 contextEpoch。对话快照只采集用户直接陈述，不将 AI 建议当成已验证材料；所有事实保留证据边界。清空后旧代次结果只用于展示，助手不会自动引用；HTML 可由用户显式选择历史文档生成。

忙碌保护覆盖实时对话、材料检查、文档生成和 HTML 转换。重启将中断任务标为失败；成功结果与助手完成消息在一次事务中更新，避免短暂状态不一致。清空使待确认上传预览失效，上传过程跨越清空也会被拒绝。

HTML iframe 不拥有同源权限，不允许联网、表单提交或外部资源。Markdown 原始 HTML 转义；内嵌图片仅允许受支持的图片 data URI，外部图片地址显示为来源文本。统计数值继续由代码计算，资料不足运行不能绕过有效数据的格式校验。

验证采用临时项目及本地模拟供应商：54 项单元/API 检查、工作台界面、研究入口、实时聊天、全部 12 模块真实 Harness SDK（含资料检查和手动 HTML），以及独立 Mac 包的 OCR、钥匙串、流式回复、提问、退出与恢复。模拟测试验证链路，不代表真实调研内容质量。未发送原项目内容到真实模型。
