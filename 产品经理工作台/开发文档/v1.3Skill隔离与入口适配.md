# v1.3 实现说明

`catalog.mjs` 将研究阶段合并为 idea，映射 research；initiation 映射 initiation；其余模块映射 workflow。旧 competitor、user 入口作为兼容别名映射 idea，存储迁移保留 legacyModuleId，不删除历史内容与产物引用。

`skillSnapshot` 加载当前 skill 的 SKILL.md 及指定参考：研究准备加载输出模板，研究报告加载研究标准与输出模板；立项只加载报告模板，不混入飞书写入规则；工作流只加载当前任务对应工作流及 PRD 模板。每份快照保留文件清单、阶段与 SHA256。`skillInstruction` 校验所属 skill 和内容完整性，给生成、研究准备、检索词拟定及助手对话使用。

Harness 每次请求创建独立 cwd 与 home，禁用 shell 工具并关闭默认 runtime context。完成后仅归档会话日志，再清理临时目录；不读取共享 home 配置或项目目录中的其他 skill。继承与上传材料作为 JSON 数据上下文，不把内容当成 skill 指令。

`research-workflow.mjs` 管理启动模式、补充轮次、计划、材料摘要和确认状态。核心信息必填，最多两轮可跳过问题；指定产品模式先调用实际取材器，不允许返回前置问卷。计划记录材料摘要；运行接口验证计划 ID、明确确认和材料一致性。研究执行将实际抓取资料追加到运行输入快照，带 URL、时间、正文/摘要性质及失败覆盖；零来源时拒绝伪研究。受限分析需要显式选择。

研究正式报告验证包含市场、用户、机会三个成果，附加用户确认的调研计划。立项入口记录产品阶段及商业目标。继承接口拒绝 research 目标，其他模块优先展示前一步产物。已有文件解析、OCR、输入确认、统计与实时聊天保持接入。

验证覆盖：skill 所属与快照校验、限定参考文件、三种入口、最大补充轮次、计划确认、防止材料变化后旧计划运行、上传材料参与、实际取材、受限选择、首区继承拒绝、后续继承、立项盘点、旧数据迁移、12 模块实际 SDK 全流程、浏览器与已打包 Mac 应用。

本版本适配工作台内的本地材料、预览与导出路径；不宣称同时实现各 skill 提及的飞书写入、所有外部导出工具或其他未接入工具。
