# v1.4.0 助手统一工作链路

本版将各模块执行收敛到右侧 AI 工作助手，中间面板负责数据采集与结果展示。每个模块仍只加载所属 Skill，不调用其他模块的 Skill。

| 区域 | 行为 |
| --- | --- |
| 数据采集 | 首区保留产品想法、指定产品、用户需求三种研究入口；其他模块支持承接已有产物。所有模块支持手动输入、文档上传、联网材料和对话补充。确认入库后，助手记录接收并使用材料。 |
| 工作助手 | 运行入口、流式聊天、工作状态、研究提问、计划确认、信息补充、材料检查和完成通知统一在助手工作链路中。对话中的生成请求进入同一运行流程。 |
| 文档大纲 | 生成前展示当前 Skill 的默认结构，可编辑保存。无独立固定大纲的模块按所属 Skill 对应章节和交付要求整理，并标明依据。运行冻结大纲，不影响旧版本。 |
| 文档展示 | 多文档列表，逐份选择。Markdown 展示标题、列表、表格、安全内嵌图片与代码；JSON 可直接查看。历史 HTML 文档继续支持隔离预览。 |
| HTML 展示 | 默认不调用模型生成 HTML。完成文档后用户逐份点击生成，缓存该版本结果并支持 HTML 导出。原型模块先生成方案文档，手动生成时再制作 HTML 原型。 |
| 总结分析 | 使用通俗摘要说明结论、局限和待验证事项，保留漏斗、留存及 A/B 计算图表。结构化数据另有查看入口。 |
| 资料不足 | 助手根据材料、直接用户陈述、工作口径和大纲检查，显示建议补充清单。用户可返回补充或明确忽略并运行；忽略不允许编造事实或绕过 CSV/统计校验。研究计划仍必须确认。 |
| 清空上下文（B） | 清空当前模块对话、已采集材料和研究准备，不触及其他模块。保留成功结果、历史版本和已保存的自定义大纲。旧结果不自动进入下一轮上下文，需要时可手动承接。 |

资料或大纲变化使先前检查失效，需重新检查。工作期间禁止清空或更改大纲；新增材料可留给下一轮，当前任务使用冻结快照。HTML 对已选文档生成，不自动改变原文档或其他产物。
