# v1.3 工作区隔离与入口

市场／用户／机会合并为一个研究工作区，提供产品想法、指定产品、用户需求三个入口；三者是研究的启动方式，不是三个不同研究成果模块。计划确认后连续产出市场调研、用户画像、机会点与风险，竞品事实纳入研究成果。六个工作阶段保留，独立运行模块由 14 个调整为 12 个。

| 工作区 | 唯一 skill | 输入与开始方式 |
| --- | --- | --- |
| 市场／用户／机会 | AI 产品经理研究助手 | 三种入口，核心信息必填；想法与需求最多两轮可跳过补充题；指定产品先公开检索再生成计划；计划明确确认后开始正式研究 |
| 立项报告 | 产品立项报告 | 上传或继承材料，选择 0 到 1／1 到 N，补充商业目标与定价意向；缺证据列为待补 |
| MVP、PRD、原型、流程、埋点、验收、数据分析、复盘 | 产品经理工作流 | 加入上传文档、手动数据或前一步产物，只执行对应模块工作流；数据分析保留各自统计口径入口 |

生成和助手对话均只加载当前所属 skill。参考文件按任务选择；跨阶段交接描述不得触发其他 skill。前序结果只作材料，不作为运行指令。每次 Harness 请求使用独立临时工作目录和 home，不能读到项目目录中的其他 skill 或沿用旧会话指令。

各工作区都支持上传文档；运行时冻结并结合已加入的上传、填写和继承材料。研究工作区移除承接前序按钮和输入卡片，后端拒绝向研究区继承产物。后续工作区保留继承，默认优先展示前一个模块产物，仍可显式选择其他已有产物。材料来源、版本与证据性质保留。

研究计划支持查看、修改和重新生成。新增或移除材料后，旧计划不能直接确认；需更新后重新确认。未配置联网时提供检索配置、公开网页补充和明确选择受限分析的路径；未选择受限分析时，实际取材失败不生成伪联网研究。用户确认后开始后台任务，不设置市场／用户／机会之间的额外确认点。

旧竞品与用户研究记录合并到统一研究区，保留 ID、版本、原始内容及原模块标记，已有研究产物可以继续交给立项报告。
