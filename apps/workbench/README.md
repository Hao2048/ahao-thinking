# 阿浩Thinking v2.9.0

基于 DeepSeek Harness 的 macOS 节点工作台。仅保留新版节点画布、节点库、项目文档与节点助手。

## 开发与打包

```sh
npm start
npm test
npm run test:nodes-ui
npm run test:node-outlines
npm run test:node-theme
npm run desktop:package
```

节点统一位于 `nodes/`，按目录自动发现，配置面板依定义生成。安装版节点在用户数据目录 `nodes/` 维护。输入、分析、报告三类节点的实现与 SOP 均由各节点包负责。

保留模型厂商＋Key 接入、流式聊天、澄清弹窗、联网取材、文件／OCR 导入、代码统计、文档大纲、Markdown／HTML／JSON 阅读、SVG 图表与导出。C 深色及银白主题共享布局，画布网格随拖动和缩放同步变化。

## 数据升级

数据目录为 `~/Library/Application Support/AIPM Workbench`。旧模块输入、对话、运行记录、研究草稿及模块上下文在首次新版启动时移除。迁移前原始存储文件先写入 `retired-module-backups/`，保持原加密格式；备份不再被工作台读取。项目身份、节点图、节点运行与文档、节点对话、模型密钥和偏好保留。旧版网页数据不再自动导入。

## 维护边界

旧六阶段页面、脚本、模块路由及其专属服务、技能快照和回归脚本已经移除。文档图表的字符图兼容转换仍用于新节点生成的文档，不属于旧界面依赖。

发布到其他电脑仍需 Developer ID 签名及公证。开发签名更新可能触发 macOS 钥匙串授权。模型回答质量需使用实际模型与材料验证。

## 专业节点与图表修订

30个节点分为输入4、分析15、报告11。管理节点点击查看SOP与完整提示词；报告只整理传入成果，相关但不足输出缺口提示，无关材料拒绝生成。点击配置页“查看已生成文档”或双击节点打开产物；“完善图表数据”支持表格与JSON编辑、校验、SVG预览及另存修订，保留原稿。
