# v1.3.2 桌面包体精简

## 发现与处理

原打包流程递归复制 Harness 完整 CLI 依赖，带入未使用的网页前端、侧栏文档预览、实验 Inspector/语音模块及 LibreOffice。桌面工作台实际使用 sdk-minimal、自己的界面、自己的文件解析/导出和原生搜索。

新增 scripts/runtime-policy.mjs：仅为 CLI 保留其启动器/命令的实际外部导入；sdk-minimal 直接挂载 SDK app 入口，因此去掉普通 SDK bundle 才会使用的 Office 和 workspace-dependencies 插件依赖。直接将 Harness 原生搜索列入生产根依赖。

移除依赖包的测试、示例、docs、类型声明、source map、tsbuildinfo 和 ExcelJS 的重复浏览器 dist；保留 JS、JSON、原生二进制、PDF 字体/cmap、许可证和第三方声明。删除 Electron 默认示例应用。未修改上游 Harness 仓库和用户 Skill 源文件。

打包后删除完整应用的 DMG staging 副本；清理了无任何脚本引用的 .desktop-tools 旧安装缓存。桌面版仍使用 public 中的 HTML/JavaScript 界面和本地服务，这些是当前功能依赖，继续保留。用户项目、密钥、历史报告和历史正式安装包保留。

- 使用精简运行资源执行 50 项单元/API 检查，全部通过，包括文件解析、统计、结构化输出、原生搜索 Key 复用和缺失结果的错误处理。

- 生产依赖目录没有断裂符号链接；检查确认网页 UI、Inspector、Office/LibreOffice 等目标包不在产物中。
- v1.3.2 打包桌面验收通过：独立启动、原生菜单、OCR、系统钥匙串加密、真实 SDK 流式对话及问题弹窗、关闭重开、退出释放端口、重启恢复。
