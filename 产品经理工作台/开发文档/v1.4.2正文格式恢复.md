# v1.4.2 正文格式恢复

## 实际故障

最新生产会话正常 completed，用户画像回复 13,193 字符。正文中的英文分类引号没有 JSON 转义，解析器在第 320 列报错。前一份市场调研回复为有效 JSON。本次不是输出额度截断。

截断仍按章节拆分；残缺 JSON 不会通过补括号变成完成结果。恢复正文不能是 JSON/HTML，必须有 Markdown 标题。Markdown 的表格、引号与 Mermaid 围栏原样保留。没有增加工作台输出额度上限。
