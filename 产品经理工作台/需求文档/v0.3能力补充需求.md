# v0.3 能力补充需求

1. 联网研究：手工关键词、公开网页地址及 AI 规划关键词三种入口，接入可配置搜索服务；结果显示正文/摘要、来源、时间和失败原因；用户确认后成为材料，模块交接保留引用。不得将网页热度当成需求已获市场验证。
2. 办公文件：PDF/DOCX/XLSX 上传后先预览、编辑、选表，再确认入库；显示原文件哈希、解析警告、工作表和编辑状态。超限或无文本明确报错。
3. 数据计算：前序交接、手工输入、文件、对话确认统一支持 CSV/JSON；漏斗、留存和两组转化 A/B 由代码计算，AI 基于结果解释并生成文档。
4. 留存：按观察截止日期区分成熟、未成熟和缺失；支持原始事件和汇总 cohort，输出热力表、汇总曲线数据及口径明细。
5. A/B：显示两组样本、转化率、绝对差值、相对提升、置信区间及双侧 p 值；小样本明确限制，不输出无根据显著性结论。
6. 桌面：继续使用 DeepSeek Harness、用户可选内部模型、系统钥匙串加密和独立本地运行时。来源链接在默认浏览器打开。

验收依据为单元测试、真实 SDK 对模拟供应商的集成测试、浏览器交互回归、实际公开网页抓取和打包运行时验证。真实模型专业质量及市场接受度需要实际研究材料与用户验证。
