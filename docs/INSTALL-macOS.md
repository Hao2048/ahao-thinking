# 阿浩Thinking · macOS 安装与升级

当前发布：**v2.9.0**。适用于 **macOS 13+、Apple Silicon（M 系列芯片）**。安装包内置 Electron、Node.js 和 DeepSeek Harness 运行环境，无需安装开发工具。

## 下载与安装

1. 打开 [v2.9.0 发布页](https://github.com/Hao2048/haohao-product-workbench/releases/tag/v2.9.0)，下载 `ahao-thinking-2.9.0-mac-arm64.dmg`。
2. 打开 DMG，将“阿浩Thinking”拖到“应用程序”。
3. 从“应用程序”启动“阿浩Thinking”，在“模型连接”填写自己的服务配置并测试连接。

当前仓库是私有仓库，下载需登录具有仓库访问权限的 GitHub 账号。此包使用本地开发签名，**没有 Apple Developer ID 签名和 Apple 公证**；macOS 可能阻止直接启动。请先确认安装包来源及校验结果，再按系统提供的安全提示处理；若设备受组织管理，请遵循其安装要求。

## 校验下载

将 DMG 与发布页中的 `SHA256SUMS.txt` 下载到同一个目录，在该目录运行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

正常应显示 `ahao-thinking-2.9.0-mac-arm64.dmg: OK`。校验失败时请重新下载，不要继续使用该文件。SHA-256 用于核对文件完整性，不代替 Apple 公证或独立的发布者身份验证。

## 从旧版本升级

1. 在旧版应用中完成或停止当前运行，按 **⌘Q** 完全退出。
2. 用新版替换“应用程序”里的旧版；不要删除应用资料目录。
3. 启动新版。签名变化可能触发钥匙串授权，需要在系统窗口完成。
4. 检查项目、模型连接和已有报告，再运行新工作流。

桌面数据位于：

```text
~/Library/Application Support/AIPM Workbench
```

应用名称已改为“阿浩Thinking”，内部存储标识仍保留兼容名称。升级前可在完全退出应用后备份整个资料目录；该目录含私人材料和加密配置，不应上传到 GitHub。

早期六阶段界面已替换为节点工作流。旧模块专属数据退出当前运行链路前，程序会把原始加密存储保存到资料目录的 `retired-module-backups/`，不把旧模块内容自动当成新节点输入。旧版网页开发数据不会自动导入桌面版。

## v2.9.0 使用提示

- 从每个工作流固定的红色“开始节点”写清产品方向和本次任务。
- 分析和报告在生成前检查资料缺口；确认意见沿连接复用，公开补充检索由已有上游联网节点执行。
- “待验证”不等于已获得真实数据。旧报告不会被自动改写，需要重新运行才会应用新规则。
- 本版本没有更新清单供应用内自动升级，本次通过下载 DMG 手动更新。
- 模型与检索服务需自己的可用连接；费用和访问权限由各自提供商决定。

详细功能与源码构建方法见[项目首页](../README.md)。
