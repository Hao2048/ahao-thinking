# v1.0 数据、取材与发布开发方案

沿用 Electron 沙箱界面、独立端口的本地 Node 服务和打包 Harness SDK。桌面主进程提供钥匙串、Apple Vision、动态页面及更新 IPC；项目服务负责材料、模型任务、确定性统计与保存。

动态读取使用临时非持久 session，无预加载和登录态。HTTP/HTTPS 经主进程受控代理，DNS 公网检查与地址固定、逐次重定向校验。仅 GET/HEAD；限制 60 请求、12 MB 总响应、45 秒读取。文本资源供渲染，禁止下载、私有网络、弹窗、写请求与系统协议；读取后销毁窗口并清理存储。脚本短暂等待并不保证所有网页完成渲染，失败需改用其他公开来源。

原始事件漏斗采用首次入口、用户去重、严格时间顺序与窗口内匹配；入口窗口未成熟的用户不计入分母。重复事件去重，同时间事件不推断先后。留存仍区分未成熟与零。连续指标使用 Welford 样本方差、Welch 自由度和 jstat t 分布；对照比较使用 Holm 校正，单独区间不作为同时置信区间。SciPy 独立核对样本：A(n=20,mean=10,sd=2)，B(n=25,mean=12,sd=3)，p=0.0106868165616，差值区间约 [0.4895746273,3.5104253727]。

更新状态由主进程 Electron autoUpdater 管理，服务经 IPC 读取和配置。立即安装先确认无运行任务，HTTP 响应后再启动 apply；主进程关闭任务服务后调用 quitAndInstall，避免安装请求与服务关闭互相等待。本地签名不启用下载。正式已下载更新可能在下一次启动应用时应用。

打包支持当前主机 arm64/x64，不跨架构复制 Node。OCR 按主机编译，应用和内置二进制正式签名；ZIP 提交公证后装订 APP，DMG 再签名、公证和装订，生成最终 ZIP 和架构 feed。凭据预检在重建产物前运行。当前只有 arm64 实机；Intel 和真实更新需单独验收。
