# v1.1 模型接入简化

普通流程：选择厂商 → 填 API Key → 保存。自动填地址、协议、模型 ID 和名称，新连接在同一存储事务中设为当前默认。连接测试保持可选，避免保存时隐式发起付费请求。

|厂商|默认模型|协议与地域|
|---|---|---|
|DeepSeek|deepseek-v4-pro|原生 Messages|
|OpenAI|gpt-5-mini|Chat Completions|
|Anthropic / Claude|claude-sonnet-5-5|Messages|
|阿里云百炼 / 通义千问|qwen-plus|OpenAI 兼容、北京|
|月之暗面 / Kimi|kimi-k3|OpenAI 兼容、中国|

普通界面折叠高级设置，展开后可以调整模型、地址、协议、名称及环境变量。选择内部服务自动展开。旧配置未标厂商时按自定义展示，不修改已有项目和密钥。编辑不回显 Key，保持原服务可留空；切换厂商清空输入，换地址或协议时服务端禁止复用原 Key，需显式提供新 Key 或环境变量。

默认值于 2026-10-09 核对官方文档：[DeepSeek](https://api-docs.deepseek.com/)、[OpenAI](https://developers.openai.com/api/docs/models/gpt-5-mini)、[Claude](https://platform.claude.com/docs/en/models/overview)、[百炼](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)、[Kimi](https://platform.kimi.com/docs/get-api-key)。百炼地域 Key 不互通，界面提示北京默认；其他地域和私有网关在高级设置修改。模型权限、余额和实际网络可用性仍由有效连接决定。

源代码测试 37 项通过；新增浏览器测试验证两项可见、预设保存、默认切换、Key 不回显和清空、内部配置和 390px 布局。三协议真实 Harness SDK 使用模拟供应商回归通过，内部配置原有完整浏览器流程通过。截图已人工查看。安装版结果见验证记录。
