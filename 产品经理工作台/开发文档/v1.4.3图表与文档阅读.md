# v1.4.3 图表与文档阅读

## 功能

- 三个模块所属 Skill 的 visualization-spec 纳入各自冻结快照；调研计划阶段仍只加载计划模板。单一 Skill 隔离保持不变。
- Markdown chart 围栏的 pm-chart-v1 规范由 ECharts 渲染；bar、line、pie、funnel、heatmap、matrix、scatter 在本地映射为白名单 option。Mermaid 源码围栏渲染流程图与关系图。数据图默认 SVG，并支持放大、SVG 和 2 倍尺寸 PNG 导出。图表库及授权文本随应用离线打包，增加约 5.9 MiB 浏览器资源，没有把开发依赖装进精简运行时。
- 定性矩阵用等级坐标，同格点位错开；悬停显示原文痛点和等级。保留来源、证据状态与数据表，缺失数值不填零。渲染错误显示原始数据和原因，不丢弃报告。
- 历史字符条形图仅在明确给出数值时重绘；字符痛点矩阵仅在邻近明细表能完整对应各点的频率与严重等级时重绘。无法可靠解释的旧图继续保留源内容，新生成文档使用图表规范。
- AI 不提供可执行 JS 或任意 ECharts option。Mermaid 设置全局 htmlLabels:false，使用 SVG 文本保留多行标签；旧图 `<br/>` 回放验证通过。禁用交互链接/初始化覆盖，严格模式与 SVG 清理移除脚本、HTML 节点及外部资源属性。
- 中间 content 去除外侧 padding；采集与结果面板贴齐左右边界。最后阅读区占一个可视高度，使滚动极限位于结果页签贴顶处。文档列表有竖向分隔线，正文独立滚动且滚动不传播，正文标题固定。未贴顶时正文上的向下滚轮先推进外层，到顶后滚正文。返回采集按钮回到前部；切换文档复位，刷新同一文档保留阅读位置。窄屏采用上下布局。
- 打包复用依赖时也刷新三个 Skill，避免发布包保留旧规范。
