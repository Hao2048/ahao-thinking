# v0.3 联网与数据开发方案

服务器继续调用官方 DeepSeek Harness SDK，不修改 Harness 核心。research.mjs 提供 Tavily、Brave、SearXNG 适配与公开网页抽取；请求限制体积和时间，解析 DNS、验证地址并固定连接目标，逐次验证重定向。macOS Clash fake-IP 的 198.18/19 域名解析使用固定 Cloudflare HTTPS DNS 获取真实公开地址后再验证；其他私网地址拒绝。

files.mjs / file-worker.mjs 在有内存和时间限制的 Worker 中解析 PDFParse、Mammoth、ExcelJS，Office ZIP 先检查解压体积。文件草稿确认前不加入输入；原始二进制不落盘，材料保留文本和来源元数据。预览草稿 15 分钟过期。

analytics.mjs 统一识别 CSV/JSON 数据，确定性计算留存和两组二元转化 A/B；漏斗复用统一读取。留存按 UTC 日期、明确事件与观察截止时间；A/B 使用合并比例 z 检验、Wilson 单组区间和 Newcombe 差值区间。期望频数不足则显著性结果为空。server.mjs 给模型提供口径和计算结果，并额外生成数值明细与来源文档，防止解释替换统计结果。

public/enhancements.mjs 增加取材、文件预览、搜索设置与统计口径界面；所有来源文字转义，链接限制 HTTP(S)，模型输出仍受原有沙箱隔离。设置接口不回显搜索密钥，变更供应商或端点不隐式复用旧密钥。

打包将生产文件库、搜索库和原生平台依赖随 Node 24 一起内置，共 840 个生产包；实际应用不依赖仓库 node_modules。代码和技能复制进入资源目录，三个源 skill 不修改。

限制：无 OCR、登录态抓取、动态网页渲染、Excel 公式求值；无多组/收入/序贯检验；无正式 Apple 签名、公证和自动更新。测试模拟模型只能证明接口和任务流程，不能验收专业文档质量。
