# v1.2.0 AI 工作助手体验

用户消息提交后立即显示并清空输入框；后端先持久化消息、返回任务 ID，再通过带本地鉴权的 SSE 推送实际模型增量。接入 Harness 的进程内 assistant-stream 通道，使用工作台自有插件转发 JSON-RPC 通知，不修改 Harness 源码、不伪造逐字播放。回复里的 JSON 元信息不显示，转义字符与跨块 Unicode 正常解码；结构化回复约定 reply 为首字段。

发送时和初次进入对话自动定位到底部，流式更新持续跟随。用户主动上翻后保留位置，出现“回到最新”按钮；回到底部后恢复跟随。重新渲染模块结果时保留滚动位置与草稿，中文输入法确认不会误触发送。Enter 发送，Shift + Enter 换行。

提问通过 AI 输出 question 结构生成原生 HTML dialog，可选选项或填写文字，最多三个问题；支持稍后回答、再次打开、跳过并标为待定义。回答作为新用户消息进入下一次 Harness 调用，保留上下文。这是工作台的结构化澄清交互，不是 Harness 所有工具权限弹窗的移植。

支持停止生成、保留部分答复与失败重试。断开窗口不停止后台任务；刷新后重新订阅最新内容。服务重启将中断的回复标为失败，已有内容和待回答问题保留。用户确认的对话材料仍需单独点击加入模块输入。

安全与持久化沿用本地鉴权、项目隔离和钥匙串加密存储。提问和 Markdown 内容均转义，不执行 AI 返回 HTML。更新安装时拒绝正在生成的对话。

验证：39 项单元/API 回归、5 项实际 Harness SDK 接口测试、完整工作流浏览器冒烟，以及长对话实时滚动、历史位置保护、弹窗、停止、重试、草稿和 390px 布局测试。SDK 实时测试在模拟供应商完成前断言首段内容已送达；真实供应商回复质量仍需已授权的有效 Key 验证。
