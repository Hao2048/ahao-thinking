# macOS 桌面版补充需求 · v0.2.0

本文件补充现有《产品经理工作台 PRD》。目标是将六阶段、14 模块的工作台变成能双击运行的 Mac 应用，以 DeepSeek Harness 作为实际执行引擎。

| 需求 | 交互与验收标准 |
|---|---|
| 独立启动 | .app 自带 Node、Harness、三个 skill；正常使用不依赖终端、浏览器或源仓库 |
| Mac 窗口 | 原生红黄绿窗口按钮、拖动区、全屏、最小化、窗口尺寸恢复、单实例 |
| 生命周期 | 关闭窗口保留任务；Dock 恢复；⌘Q 退出并关闭后台服务；意外退出的任务重启后标记失败可重试 |
| 菜单与快捷键 | ⌘N 新建项目，⌘, 模型设置，原生编辑/缩放菜单，数据目录入口 |
| 模型设置 | 多个连接、内部兼容 API、默认模型选择、模型 ID 与协议可配置，连接测试实际调用 Harness |
| 模块化 | 任意模块可独立进入；继承前序、手工/上传、对话确认三种输入；保留版本和来源 |
| 数据迁移 | 首次启动导入现有网页版本项目、模型和会话；桌面目录已有数据时不覆盖；原目录保持完整 |
| 本地存储 | 项目及模型配置 state.json 通过 macOS 钥匙串加密；会话日志留在私有应用目录 |
| 文件输出 | 文档预览和保存使用已有模块；下载由原生保存对话框选位置 |
| 安装交付 | Apple Silicon/macOS 13+ 的 .app 和 DMG；本次是本地开发签名 |

专业能力沿用首版边界：立项仅含 MVP 简介，完整 MVP 和 PRD 由产品经理工作流负责。尚不支持自动联网研究、PDF/Word/Excel 二进制解析、自动更新、团队协作；真实模型输出质量需用户材料与真实服务验收。
